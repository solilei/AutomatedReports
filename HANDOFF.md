## Decisions made
- Django 5.2 LTS + openpyxl, pyotp, segno, msal (approved). PLAN.md D1–D18 accepted.
- Averages rounded half up to whole numbers (2.5 → C). Total = sum of six (6–30).
- One group per upload, typed by the admin each time (box starts empty); the group number is the course.
- `.xlsx` only, 5 MB max. The last admin can't be demoted or deactivated.
- Slice 1 to 25 tests are frozen (except as changed at the user's request, see above): don't modify test files unless the user asks.
- 2026-10-26 user decisions from the review: digit-only IDs ignore leading zeros (R6); a missing row in a saved set counts as 3 (R8); admin can discard uploads, no automatic deletion (R11); block renaming a subject used by a locked or archived group (R12); proof of concept stays local for now (Microsoft-only admin sign-in and `DEBUG` default deferred).
- My defaults, stated to the user and not objected to: group number needs a letter or digit (R4); 200/50 character limits from the model fields (R5); inactive subjects block new sets only (R7); unarchive restores the earlier status (R9); 5 failures → 15-minute lock, shared by password and MFA codes (R10); stale preview shows a warning and keeps Confirm enabled (R3).
- OneDrive can't host the app (file storage only); `docs/HOSTING.md` recommends Azure App Service in the same tenant.
